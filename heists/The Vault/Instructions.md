🔑 Step 0: Role Selection

At /heist start, players join and pick one role:
	•	🕵️ Hacker → handles tech (cameras, keypads, alarms).
	•	💪 Muscle → deals with guards, distractions, breaking doors.
	•	🎭 Con Artist → blends in, talks/bribes past obstacles.
	•	🚗 Driver → ensures escape, handles vehicles.

If a role isn’t filled, the group will face harder checks later.

⸻

🟢 Stage 1: Infiltration (Con Artist Test)

Narration:
“The casino lobby is packed. Guards are checking IDs at random. Can you talk your way through?”

Action:
	•	🎭 Con Artist rolls persuasion (d100 ≥ 60).
	•	If no Con Artist, group must all roll stealth (≥ 55).

Failure: Suspicion +1. Guards are watching closely.

⸻

🔵 Stage 2: Security Cameras (Hacker Test)

Narration:
“Rows of cameras line the walls. Someone needs to disable the feed.”

Action:
	•	🕵️ Hacker rolls (d100 ≥ 55).
	•	If no Hacker, group must solve a logic puzzle (e.g., number sequence, riddle).

Failure: Suspicion +1, guards alerted.

⸻

🟡 Stage 3: Hallway Patrol (Muscle Test)

Narration:
“Two guards are blocking the way to the vault.”

Action:
	•	💪 Muscle rolls (d100 ≥ 65).
	•	If multiple Muscle players, each rolls → only one success needed.
	•	If no Muscle, group must sneak (all roll stealth ≥ 45).

Failure: Alarm triggered → Suspicion +2.

⸻

🔴 Stage 4: The Vault Lock (Hacker + Con Artist Combo)

Narration:
“The vault has a triple-coded lock: a keypad and voice recognition system.”

Action:
	•	🕵️ Hacker rolls (≥ 70) to bypass keypad.
	•	🎭 Con Artist imitates voice ID (≥ 65).
	•	If both succeed → vault opens clean.
	•	If one fails → vault still opens, but suspicion +1.
	•	If no Hacker/Con Artist → wire-cut puzzle (vote Red/Blue/Green).

Failure: Wrong wire → lose 25% loot.

⸻

🟣 Stage 5: Heavy Door (Muscle Test)

Narration:
“The vault door is open, but the last metal bar is jammed. It won’t budge.”

Action:
	•	💪 Muscle rolls (≥ 60) to break it open.
	•	If no Muscle → group must vote to spend explosives (lose 10% loot).

Failure: Door takes too long → suspicion +1.

⸻

🟤 Stage 6: Escape (Driver Test)

Narration:
“Alarms are blaring. Time to escape before the police arrive.”

Choices:
	•	🚗 Car Chase: Driver rolls (≥ 65). Fail → crash, lose 50% loot.
	•	🚁 Helicopter Pickup: Pay 15% loot. Auto success.
	•	🕳️ Sewer Tunnel: Group puzzle (emoji sequence). If any fail → lose 25% loot.

Special Rule:
	•	If no Driver → group must vote alternative escape (Helicopter/Sewer).

⸻

🟤 Stage 6: The Loot Grab (Full Team Test) 👫

Narration:
“Inside the vault are stacks of cash, chips, and gold bars. But an automated security system is counting down. You must move fast as a team!”

Action (All Players Work Together):
	•	Every player must roll a “loot grab” (d100).
	•	Target = 50 or higher.
	•	Each success adds loot to the total.
	•	Each failure adds +1 to suspicion (tripping sensors).

Special Twist:
	•	Players can choose “Greedy Grab” (target 65+ but double loot if success, suspicion +2 if fail).
	•	Forces team to balance risk/reward.

Resolution:
	•	More successes = bigger payout.
	•	Too many failures = suspicion skyrockets → harder escape.

⸻

⚫ Stage 7: Escape (Driver Test / Group Choice)

(Driver handles car chase, or group does sewer puzzle / helicopter buyout.)

⸻

💎 Rewards
	•	Base = 1.1M × players.
	•	No suspicion triggered → +50% loot.
	•	Suspicion > 0 → -25% loot.
	•	Suspicion ≥ 3 → police swarm → total failure.
	•	Random 5% Legendary Reward (cosmetic/title).
