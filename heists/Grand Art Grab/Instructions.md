🔑 Step 0: Role Selection
	•	🕵️ Hacker → disables motion sensors, unlocks storage crates.
	•	💪 Muscle → neutralizes guards, carries heavy frames.
	•	🎭 Con Artist → mingles with guests, identifies fakes, smooth-talks staff.
	•	🚗 Driver → themed as Getaway Courier (van, truck, or airlift).

⸻

💰 Payout System
	•	Base Loot = 3M × players (high-value artwork).
	•	Bonus paintings/jewels from team stages.
	•	Suspicion Meter = Security Level.
	•	Security Level ≥ 3 = vault lockdown, total fail.

⸻

🎨 Stages

⸻

🟢 Stage 1: Gala Infiltration (Con Artist Test)

Narration:
“Dressed in tuxedos, you blend into the gala. Security checks VIP wristbands at the door.”

Action:
	•	🎭 Con Artist rolls persuasion (d100 ≥ 70).
	•	If no Con Artist → all roll stealth (≥ 60).

Failure: Security +1.

⸻

🔵 Stage 2: Motion Sensors (Hacker Test)

Narration:
“Laser sensors scan the gallery floor.”

Action:
	•	🕵️ Hacker rolls (d100 ≥ 70).
	•	If no Hacker → group emoji puzzle (⬆️⬅️⬆️➡️⬇️) with exact sequence.

Failure: Security +1.

⸻

🟡 Stage 3: Suspicious Guest (Con Artist Test)

Narration:
“A wealthy guest questions your presence.”

Action:
	•	🎭 Con Artist rolls (d100 ≥ 65).
	•	If no Con Artist → pay 10% loot in a bribe.

Failure: Security +1.

⸻

🔴 Stage 4: Fake or Real? (Full Group Deduction)

Narration:
“Several paintings look identical. Only the real one holds the jackpot value.”

Action (All Players):
	•	Bot provides 3 painting titles (e.g., Celestial Dawn, Dawnlight, Morning Bloom).
	•	Team must vote which one is real.
	•	Correct → jackpot secured.
	•	Wrong → Security +2, loot -25%.

⸻

🟣 Stage 5: Guard Interruption (Muscle Test)

Narration:
“Two guards patrol near the storage door.”

Action:
	•	💪 Muscle rolls (d100 ≥ 75).
	•	If no Muscle → all stealth rolls (≥ 55).

Failure: Security +2.

⸻

🟤 Stage 6: Storage Crates (Hacker + Muscle Combo)

Narration:
“The artwork is locked in a heavy crate with a biometric lock.”

Action:
	•	🕵️ Hacker rolls (≥ 75) to override scanner.
	•	💪 Muscle rolls (≥ 70) to lift and move the crate.
	•	Both succeed → full success.
	•	If one fails → crate opens, but Security +1.
	•	If no Hacker/Muscle → fallback = riddle (“What has hands but can’t clap?” → Clock).

⸻

⚫ Stage 7: Grab & Pack (Full Team Test)

Narration:
“Dozens of paintings, jewels, and statues glimmer. Time is short.”

Action:
	•	Each player rolls (d100 ≥ 60).
	•	Success = +1 bonus item (worth 1M).
	•	Fail = Security +1.

Optional Greedy Grab:
	•	Roll ≥ 80. Success = +2 bonus items. Failure = Security +2.

⸻

🟣 Stage 8: Rooftop Escape (Driver Test / Group Choice)

Narration:
“Alarms echo as skylights shatter open to the night.”

Choices:
	•	🚛 Truck Loadout: Driver rolls (d100 ≥ 70). Fail = crash, -50% loot.
	•	🏍️ Motorcycle Couriers: Driver rolls (≥ 75). Success = +10% loot. Fail = wipeout, -25% loot.
	•	🚁 Helicopter Lift: Costs 20% loot. Auto success.

⸻

💰 Rewards
	•	Base = 3M × players.
	•	Bonus items from Stage 7.
	•	+50% if Security = 0.
	•	-25% if Security > 0.
	•	Security ≥ 3 = vault lockdown, total fail.
	•	Legendary 5% drop → “Master Forger” title.
