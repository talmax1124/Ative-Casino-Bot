🔑 Step 0: Role Selection
	•	🕵️ Hacker → cracks ICE, decodes firewalls, outsmarts AI.
	•	💪 Muscle → handles corp security squads, brute forces doors.
	•	🎭 Con Artist → manipulates staff, bluffs as corporate execs.
	•	🚗 Driver → themed as Cyber Runner (navigates digital escape routes, pilots hoverbike getaway).

⸻

💰 Payout System
	•	Base Loot = 2.5M × players (higher stakes).
	•	Bonus “crypto keys” collected in group stages (worth 1M each).
	•	Suspicion Meter = System Trace Level.
	•	Trace ≥ 3 = AI locks system, total failure.

⸻

⚡ Stages

⸻

🟢 Stage 1: Corp Lobby Entry (Con Artist Test)

Narration:
“You enter NeoCorp HQ disguised as executives. The receptionist AI scans badges.”

Action:
	•	🎭 Con Artist rolls (d100 ≥ 70).
	•	If no Con Artist → everyone stealth rolls (≥ 60).

Failure: Trace +1.

⸻

🔵 Stage 2: Firewall Gate (Hacker Test)

Narration:
“The firewall pulses like molten glass. Only precision hacking will breach it.”

Action:
	•	🕵️ Hacker rolls (d100 ≥ 70).
	•	If no Hacker → typing race: first player to type “OVERRIDE” within 5s.

Failure: Trace +1.

⸻

🟡 Stage 3: Patrol Security Squad (Muscle Test)

Narration:
“Heavily armed corp guards march the hallways. They spot movement.”

Action:
	•	💪 Muscle rolls (d100 ≥ 75).
	•	If no Muscle → group vote:
	1.	Con Artist bluff (lose 15% loot).
	2.	Everyone stealth roll (≥ 55).

Failure: Trace +2.

⸻

🔴 Stage 4: ICE Puzzle (Hacker + Con Artist Combo)

Narration:
“The ICE barrier manifests as a glowing digital guardian that demands a passphrase.”

Action:
	•	🕵️ Hacker rolls (≥ 75) to weaken ICE.
	•	🎭 Con Artist rolls (≥ 70) to deliver bluff passphrase.
	•	If both succeed → ICE collapses.
	•	If one fails → ICE weakens but Trace +1.
	•	If no Hacker/Con → Group riddle: “I speak without a mouth and hear without ears. What am I?” → (Echo).

⸻

🟣 Stage 5: AI Showdown (Muscle + Hacker Test)

Narration:
“A rogue AI materializes, defending the vault with cyber-claws and lasers.”

Action:
	•	💪 Muscle rolls (≥ 75) to hold off AI’s attacks.
	•	🕵️ Hacker rolls (≥ 80) to inject virus.
	•	If both succeed → AI defeated.
	•	If one fails → vault opens but Trace +1.

⸻

🟤 Stage 6: Crypto Key Grab (Full Team Test)

Narration:
“The vault splits open, revealing glowing crypto keys suspended in air.”

Action (All Players):
	•	Each rolls (d100 ≥ 60).
	•	Each success = +1 key (worth 1M).
	•	Each fail = Trace +1.

Optional Risk:
	•	Overclock Grab: Roll ≥ 80. Success = +2 keys. Failure = Trace +2.

⸻

⚫ Stage 7: Digital Escape (Group Puzzle)

Narration:
“The vault begins collapsing in neon shards. The only way out is to follow the correct exit path.”

Action:
	•	Emoji sequence puzzle: 🔴🟢🔵🟡⬆️⬇️.
	•	All players must complete correctly.
	•	Any mistake = Trace +1 + loot -25%.

⸻

🟣 Stage 8: Street Getaway (Driver Test)

Narration:
“You jack into your hoverbikes, the city skyline rushing by. Corp drones chase from above.”

Choices:
	•	🏍️ Hoverbike Chase: Driver rolls (d100 ≥ 75). Success = clean getaway. Fail = wipeout, -50% loot.
	•	🚛 Armored Van: Driver rolls (≥ 70). Success = safe but slower. Fail = -25% loot.
	•	🚁 Stealth Drop-ship: Costs 20% loot. Auto success.

⸻

💰 Rewards
	•	Base = 2.5M × players.
	•	+1M per crypto key from Stage 6.
	•	+50% if Trace = 0.
	•	-25% if Trace > 0.
	•	Trace ≥ 3 = system lockout, full fail.
	•	Legendary 5% drop → “Neon Phantom” title.
