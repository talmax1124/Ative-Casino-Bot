🔑 Step 0: Role Selection
	•	🕵️ Hacker → disables biometric scanners, overrides nuclear-level systems.
	•	💪 Muscle → fights soldiers, smashes vault reinforcements.
	•	🎭 Con Artist → poses as generals, bluffs officials, manipulates personnel.
	•	🚗 Driver → themed as Escape Specialist (pilots submarine, drives convoy, flies stolen jet).

⸻

💰 Payout System
	•	Base Loot = 5M × players (biggest yet).
	•	Bonus classified items/artifacts (worth 2M each) from group grabs.
	•	Suspicion Meter = Containment Level.
	•	Containment ≥ 3 = nuclear lockdown, fail.

⸻

🔥 Stages

⸻

🟢 Stage 1: Military Checkpoint (Con Artist Test)

Narration:
“The crew arrives at the outer base disguised as officers. Armed guards demand clearance codes.”

Action:
	•	🎭 Con Artist rolls (d100 ≥ 75).
	•	If no Con Artist → all stealth rolls (≥ 65).

Failure: Containment +1.

⸻

🔵 Stage 2: Perimeter Drones (Hacker Test)

Narration:
“Swarm drones patrol the fence with heat scanners.”

Action:
	•	🕵️ Hacker rolls (d100 ≥ 75).
	•	If no Hacker → group typing race (first to type “OVERRIDE PROTOCOL” in 7s).

Failure: Containment +1.

⸻

🟡 Stage 3: Patrol Squad (Muscle Test)

Narration:
“A squad of soldiers rounds the corner with rifles ready.”

Action:
	•	💪 Muscle rolls (d100 ≥ 80).
	•	If no Muscle → group stealth (≥ 60).

Failure: Containment +2.

⸻

🔴 Stage 4: Biometric Scanner (Hacker + Con Artist Combo)

Narration:
“The vault door is locked by fingerprint + voice recognition.”

Action:
	•	🕵️ Hacker rolls (≥ 80) to bypass scanner.
	•	🎭 Con Artist rolls (≥ 75) to mimic general’s voice.
	•	Both succeed = silent entry.
	•	One fails = door opens but Containment +1.
	•	No Hacker/Con → fallback riddle: “I’m always running, but never move. What am I?” → Time.

⸻

🟣 Stage 5: Steel Blast Doors (Muscle Test)

Narration:
“Beyond the scanner lies a 3-foot thick steel blast door.”

Action:
	•	💪 Muscle rolls (≥ 80).
	•	If fail/no Muscle → explosives used, loot -10%.

⸻

🟤 Stage 6: Nuclear Protocol AI (Hacker Test)

Narration:
“A defense AI wakes up, demanding nuclear clearance codes.”

Action:
	•	🕵️ Hacker rolls (≥ 85).
	•	If fail/no Hacker → group puzzle: unscramble “ATOMIC” within 10s.

Failure: Containment +1.

⸻

⚫ Stage 7: Vault Access (Full Team Puzzle)

Narration:
“The vault has a triple-lock requiring simultaneous entry codes.”

Action (All Players):
	•	Emoji sequence: 🔴🟢⬆️⬇️➡️⬅️.
	•	ALL must input correctly.
	•	Any fail = Containment +1.

⸻

🟠 Stage 8: Treasure Grab (Full Team Test)

Narration:
“Inside: gold, secret artifacts, and nuclear bonds.”

Action:
	•	Each player rolls (d100 ≥ 65).
	•	Success = +1 classified item (worth 2M).
	•	Fail = Containment +1.

Optional Greedy Grab:
	•	Roll ≥ 85. Success = +2 items. Failure = Containment +2.

⸻

🟢 Stage 9: Helicopter Ambush (Muscle Test)

Narration:
“As alarms blare, a helicopter gunship swoops overhead.”

Action:
	•	💪 Muscle rolls (d100 ≥ 80) with rocket launcher.
	•	If no Muscle → group must pay 15% loot for EMP strike.

Failure: -25% loot.

⸻

🔵 Stage 10: The Escape (Driver Test / Group Choice)

Narration:
“The military converges. The crew must vanish before missiles launch.”

Choices:
	•	🚛 Convoy Trucks: Driver rolls (d100 ≥ 75). Fail = crash, -50% loot.
	•	🛩️ Stolen Jet: Driver rolls (≥ 80). Success = +15% loot. Fail = -25% loot.
	•	🚢 Submarine Escape: Costs 20% loot. Auto success.

⸻

💰 Rewards
	•	Base = 5M × players.
	•	Extra classified items (2M each) from Stage 8.
	•	+50% if Containment = 0.
	•	-25% if Containment > 0.
	•	Containment ≥ 3 = nuclear lockdown, full fail.
	•	Legendary 5% drop → “Omega Thief” title.

⸻

✨ Why This is the Finale
	•	10 stages → longest, hardest heist.
	•	Highest base payout (5M each).
	•	Multiple combo stages (Hacker+Con, full-team locks, Greedy Grab).
	•	Epic escape choices (jet, submarine, convoy).
	•	Feels like the endgame challenge.
