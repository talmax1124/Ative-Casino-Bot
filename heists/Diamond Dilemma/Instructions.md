🔑 Step 0: Role Selection
	•	🕵️ Hacker → disables lasers and alarms.
	•	💪 Muscle → handles guards or smashing obstacles.
	•	🎭 Con Artist → distracts, talks/bribes staff.
	•	🚗 Driver → escape route via van or motorcycle.

⸻

🟢 Stage 1: Sneaking Into the Gala (Con Artist Test)

Narration:
“The museum is hosting a fancy gala. Guests are arriving in tuxedos and gowns. The guards are sharp. Can you blend in?”

Action:
	•	🎭 Con Artist rolls persuasion (d100 ≥ 60).
	•	If no Con Artist, everyone rolls stealth ≥ 55.

Failure: Suspicion +1 (guards suspicious of uninvited guests).

⸻

🔵 Stage 2: Laser Grid (Hacker Test)

Narration:
“The diamond hall is protected by a glowing laser grid. Touch the wrong beam and the alarm blares.”

Action:
	•	🕵️ Hacker rolls hacking check (d100 ≥ 65).
	•	If no Hacker: Group puzzle — type the correct emoji sequence 🔴🟢🔵🟡 in order (like Simon Says).
	•	If anyone messes up → suspicion +1.

⸻

🟡 Stage 3: Suspicious Guard (Muscle Test)

Narration:
“A guard notices the team lingering near the diamond wing. He’s coming closer.”

Action:
	•	💪 Muscle rolls strength (d100 ≥ 65) to knock him out silently.
	•	If no Muscle: Group vote →
	1.	Con Artist bribe (lose 10% loot).
	2.	Everyone roll stealth (≥ 50).

Failure: Guard triggers alarm → suspicion +2.

⸻

🔴 Stage 4: Diamond Case Lock (Hacker + Con Artist Combo)

Narration:
“The diamond is inside a high-tech glass case with both a keypad and a voice recognition system.”

Action:
	•	🕵️ Hacker rolls (d100 ≥ 70) to disable keypad.
	•	🎭 Con Artist rolls (d100 ≥ 65) to fake the curator’s voice.
	•	If both succeed → case opens silently.
	•	If one fails → case opens but suspicion +1.
	•	If no Hacker/Con Artist → word scramble puzzle (e.g., unscramble “DIAMOND”) with limited time.

⸻

🟣 Stage 5: Emergency Backup Guard (Muscle Test)

Narration:
“As you grab the diamond, a second guard bursts in from the hallway!”

Action:
	•	💪 Muscle rolls (d100 ≥ 60).
	•	If fail or no Muscle → guard shouts → suspicion +1.

⸻

🟤 Stage 6: The Loot Grab (Full Team Test)

Narration:
“Alarms start a soft countdown. You must snatch what you can before security shutters lock the gallery.”

Action (All Players Work Together):
	•	Each player rolls a grab check (d100 ≥ 50).
	•	Each success = +500 coins added.
	•	Each fail = +1 suspicion.

Optional Risk:
	•	A player may declare Greedy Grab → target = 65+, but loot = +1000 coins if successful. Failure = suspicion +2.

⸻

⚫ Stage 7: Escape (Driver Test / Group Choice)

Narration:
“Sirens are starting to wail. How do you escape the museum grounds?”

Choices:
	•	🚗 Getaway Van: Driver rolls (d100 ≥ 65). Fail → crash → lose 50% loot.
	•	🛵 Motorcycle Blitz: Driver rolls (≥ 70). Success = faster escape, loot multiplier +10%. Fail = wipeout, lose 25% loot.
	•	🕳️ Sewer Tunnel: Group maze puzzle (emoji path). Fail = suspicion +1 + lose 25% loot.
	•	🚁 Helicopter Buyout: Costs 15% loot, guaranteed success.

⸻
Base Loot = 1,000,000 × # of players.


Bonus loot from Stage 6 grab rolls.

	•	+50% if suspicion = 0.
	•	-25% if suspicion > 0.
	•	Suspicion ≥ 3 = fail, team caught.
	•	5% Legendary Drop = “Diamond Hands” badge.
