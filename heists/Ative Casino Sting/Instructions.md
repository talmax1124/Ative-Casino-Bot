🔑 Step 0: Role Selection
	•	🕵️ Hacker → disables digital systems, cracks vault AI.
	•	💪 Muscle → fights bouncers, moves heavy safes.
	•	🎭 Con Artist → poses as VIP guest, distracts staff.
	•	🚗 Driver → themed as Pilot/Escape Driver (controls the final getaway).

⸻

💰 Payout System
	•	Base Loot = 2M × players (bigger stakes for high-class heist).
	•	Extra chips/artifacts collected during group stages.
	•	Suspicion Meter = Alert Level.
	•	If Alert Level ≥ 3, security drones swarm → full failure.

⸻

✈️ Stages

⸻

🟢 Stage 1: Boarding the Sky Casino (Con Artist Test)

Narration:
“The casino is mid-flight, and the only entry is through the luxury boarding ramp. Guards check invites.”

Action:
	•	🎭 Con Artist rolls persuasion (d100 ≥ 70).
	•	If no Con Artist → all roll stealth (≥ 60).

	 

Failure: Alert +1.

⸻

🔵 Stage 2: Drone Patrol (Hacker Test)

Narration:
“Automated drones scan the halls for intruders.”

Action:
	•	🕵️ Hacker rolls (d100 ≥ 70) to jam signals.
	•	If no Hacker → group typing race (type “JAMMED” in 5s).

Failure: Alert +1.

⸻

🟡 Stage 3: VIP Lounge Bluff (Con Artist Test)

Narration:
“Bouncers stop the team in the VIP lounge. They demand to see your guest list entry.”

Action:
	•	🎭 Con Artist rolls (d100 ≥ 65).
	•	If no Con Artist → pay 10% loot as bribe.

Failure: Alert +1.

⸻

🔴 Stage 4: Security Bouncers (Muscle Test)

Narration:
“Two massive bouncers block the elevator to the vault deck.”

Action:
	•	💪 Muscle rolls (d100 ≥ 75).
	•	If no Muscle → all players roll stealth (≥ 55).

Failure: Alert +2.

⸻

🟣 Stage 5: AI Vault Lock (Hacker + Con Artist Combo)

Narration:
“The vault is controlled by a smug AI voice system. One must hack the core while another impersonates the owner.”

Action:
	•	🕵️ Hacker rolls (≥ 75).
	•	🎭 Con Artist rolls (≥ 70).
	•	If both succeed → vault opens silently.
	•	If one fails → vault opens but Alert +1.
	•	If neither role → fallback puzzle: unscramble “CASINO” within 20s.

⸻

🟤 Stage 6: Chip & Treasure Grab (Full Team Test)

Narration:
“The vault bursts open, revealing piles of high-value casino chips and artifacts glowing under lights.”

Action (All Players):
	•	Everyone rolls (d100 ≥ 55).
	•	Each success = +1 chip case (worth 750k).
	•	Each fail = Alert +1.

Optional Risk:
	•	High-Roll Grab: Roll ≥ 75. Success = +2 chip cases. Failure = Alert +2.

⸻

⚫ Stage 7: Rooftop Run (Group Action)

Narration:
“Alarms flash red. Guards swarm. The only way out is across the skyship’s rooftop as spotlights chase you.”

Action:
	•	Group emoji sequence challenge: ⬆️➡️⬇️⬅️⬆️.
	•	All players must complete correctly.
	•	Any mistake = Alert +1 + loot -25%.

⸻

🟤 Stage 8: Final Escape (Driver/Pilot Test)

Narration:
“At the edge of the skyship, your escape rides wait. It’s all or nothing.”

Choices:
	•	🚁 Helicopter Pickup: Driver rolls (d100 ≥ 70). Fail = crash, -50% loot.
	•	🪂 Parachute Drop: All players roll (≥ 60). Failures = -25% loot each.
	•	🚀 Hijack Shuttle: Costs 20% loot. Guaranteed success.

⸻

💰 Rewards
	•	Base = 2M × players.
	•	Extra chip cases (750k each) from Stage 6.
	•	+50% if Alert = 0.
	•	-25% if Alert > 0.
	•	Alert ≥ 3 = caught by drones, full fail.
	•	Legendary 5% drop → “Sky Thief” badge.
