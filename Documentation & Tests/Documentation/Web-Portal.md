# Web Portal ATIVE CASINO Documentation

Technologies:

- React
- Firebase
- Tailwind CSS

## Overview

The Web Portal for ATIVE CASINO is a user-friendly interface that allows users to interact with the casino's services. It has been designed with a focus on usability and accessibility, ensuring that users can easily navigate and utilize the platform. Players can login with their discord accounts, and view stats, leaderboards, purchase in-game currency, purchase shop items with the in game currency that will help users progress in the economy ecosystem and games.

## Features

- **User Authentication**: Secure login and registration using Discord accounts.
- **Dashboard**: Overview of user stats, recent activities, and notifications.
- **Leaderboards**: Display of top players and their rankings.
- **In-Game Currency**: Purchase and manage in-game currency for use in various games
- **Shop**: Browse and purchase items that enhance gameplay and user experience.
- **Responsive Design**: Optimized for both desktop and mobile devices.
- **Real-Time Updates**: Instant updates on user stats and leaderboard positions.
- **Secure Transactions**: Safe and secure payment processing for in-game purchases.
- **Square Payment Integration**: Seamless integration with Square for handling payments and transactions.
- **Firebase Backend**: Utilizes Firebase for real-time database management and user authentication.

## Installation Railway & Testing Locally

1. Clone the repository:
   ```bash
   git clone
   ```
2. Navigate to the project directory:
   ```bash
   cd web-portal
   ```
3. Install dependencies:
   ```bash
   npm install
   ```
4. Set up environment variables:
   - Create a `.env` file in the root directory.
   - Add the necessary Firebase and Square configuration variables.

5. Start the development server:
   ```bash
   npm start
   ```
6. Open your browser and navigate to `http://localhost:3000` to view the portal.
7. To run tests, use the following command:
   ```bash
   npm test
   ```
